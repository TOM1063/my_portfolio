手と手をとりあう大テーブル

Photo by Hayato Kurobe

大学施設用の作業テーブル。通常時は1220*2440mmの大きな作業台, 展示時には半分に分割して作品の陳列に使用することができる。

机同士をしっかりと、簡単に繋げることができる機構を考えていくと、自然と机同士が手と手を取り合うような印象を持ち始めた。それはこの製図室という、誰かと共に発想を形にしていく場の空気に共鳴しはじめる。

A work table for university facilities. Normally, it is a large workbench measuring 1220*2440mm, but during exhibitions, it can be split in half and used to display works.

We aimed to create an impression of the tables strongly holding hands with each other, resonating with the atmosphere of a place where ideas are shaped together with others.

Optimal Design

全部で18台もの机の制作を,製図室に隣接するShopBotルームで行う必要があることから、作業効率性と廃棄物削減の観点から、極限まで歩留を高めることを意識した。

結果的に、一台当たりのパーツを合板2枚分に納め、歩留率85%以上に至った。

By using image analysis, we extracted time-based handwriting data from freehand drawings on an iPad. We then built a system that reads the data on a web application, reproduces the brush strokes, and enables interaction with the displayed lines.

Now, we can treat drawings not as completed works but as processes with time.
